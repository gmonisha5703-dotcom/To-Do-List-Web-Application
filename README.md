# To-Do List Web Application

## Project Description
A simple To-Do List web application developed using HTML, CSS, and JavaScript to manage daily tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Add New Tasks
- View Task List
- Manage Daily Activities
- Simple User Interface
- Interactive Task Management

## How to Run
1. Download the project.
2. Open the index.html file in a web browser.
3. Enter a task.
4. Click Add Task.

## Project Objective
To help users organize and manage their daily activities efficiently.
